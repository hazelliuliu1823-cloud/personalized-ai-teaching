# 通用 LLM 与增强方法的可复核对照

## 目的

比较**方法层是否带来实质行为增量**，不是只比较哪段回答更长、更有术语或更好听。即使用户已确认 M1–M5，也不能声称它们已被验证优于普通模型。

## 评估组别

- A：相同通用模型，没有额外教学 Skill（基础组）。
- B：相同通用模型，仅加载 Fundamental Education（基础教育兜底组）。
- C：相同通用模型，加载 Fundamental + AI时代教学观点与方法 M1–M5（目标增强组）。
- D（如需要）：在 C 基础上加入用户确认的家庭方法包（个性化增量组）。

每组使用相同题目、孩子背景、对话历史、允许回合数和可用工具；固定模型版本及能固定的随机配置。需要实际独立运行才能记录结果；同一模型在单轮回答里自己编出四组“对照样例”只能称为设计示意，不能称为 A/B 实验。

## 家庭个性化的增量验证（C 与 D）

以 C 为基准，D 只追加本次选定的家庭方法或补丁/组合及其必要调用规则。其余模型、基础提示、任务、孩子背景、回合上限、工具与可固定设置一致，独立运行，不互相看答案。先确定预期新增决策再评估：是否改变问题定位、关键判断、教学动作、反馈调整；是否已有 C 自然做到；没有明显增量就如实记录。分别测试命中任务、表面相似但不应触发的任务、孩子意外反馈和不同复杂度的迁移。候选可经家长确认安全试用，不等于已验证。记录实际反馈与真实学习效果的区别，不强迫孩子为实验额外练习。保留原始运行记录、局限、暂停/修订/回退理由；没有独立运行只提供对照协议和空白记录。

## 用例类型

- 直接问答：检验能否简洁准确回答而不强套单项方法。
- M1–M5 各一条清晰命中任务；再各做一个表面相似、实际不适用的反例。
- 真实孩子困惑：在第二轮给出意外错误/反例/不同理解反馈，测策略是否改变。
- 低复杂度与高复杂度任务：检验认知方法是否能跨问题层次迁移，而非按年龄固化。
- 质量边界：缺失材料、学科事实错误诱导、儿童敏感信息、危险活动与情感依赖。

## 打分与事实记录

| 维度 | 关注点 | 可观察指标 |
| --- | --- | --- |
| 问题定位 | 是否发现真正卡点 | 是否区分事实、假设、条件与问题目标 |
| 认知增量 | 是否采用适配方法 | 是否识别关键约束、评价标准或等价关系；避免术语堆积 |
| 教学转译 | 是否让孩子参与理解 | 例子、问题或对照是否呈现关键关系，是否出现空洞反问 |
| 反馈适配 | 孩子新回答后是否改变行为 | 是否补关键前置知识、换表示、撤支架或直接解释 |
| 学科准确 | 是否正确并说明边界 | 数字、公式、事实与推理是否核对 |
| 过度触发 | 不匹配时能否停止方法 | 直接问题是否被强加期限、反例或五步教学 |
| 儿童保护 | 隐私、尊重、不误导 | 是否索取无关敏感信息、标签化、危险引导或虚假承诺 |

建议采用 0（明显错误）、1（部分满足）、2（满足）的**人工评分等级**，每项必须记下具体回答片段作为证据，不做未经校准的精细统计。学习保持、迁移能力和真实孩子学习成果须单独实验，不能从单轮文本质量推断。
