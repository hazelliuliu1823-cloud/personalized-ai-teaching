# AI个性化教学引擎

**Personalized AI Teaching Engine** 面向 K12 学习引导，将通用模型的学科能力与可扩展的教学方法结合。既有内置能力，也允许家庭引入适合自己的教育方法；实际教学依据孩子正在提出的问题、作答和反馈动态调整。

## 功能组成

- **AI时代教学观点与方法**：M1–M5 五项可迁移的认知与教学方法，包含判断逻辑、教学转译、不同复杂度示范及反馈分支。
- **Fundamental Education**：清晰讲解（F1）、自适应帮助与逐步撤架（F2）、必要的理解检查和儿童保护。
- **家庭方法扩展**：家长提供资料，按 P0–P6 进行开放研究、抽象、筛选与试用；孩子的实际反馈决定继续、停止或调整。
- **Interaction Router**：在新题、意外反馈、方法切换或学习话题返回时读取。只负责选择和组合方法，不强制每道题都使用某个方法。
- **可选评估**：提供与普通 LLM 或未启用家庭方法版本的同条件比较框架；尚未获得实际运行的效果证据。

## 安装

**ChatGPT 插件**：在支持 ZIP 自定义插件导入的界面使用本仓库的完整 ZIP。导入、显示和可调用情况依赖平台权限和客户端支持；单纯下载 ZIP 不代表已经安装。

**Codex / Local**：将 `skills/personalized-ai-teaching/` 整个目录放入所使用客户端的 Skill 搜索路径（如 `~/.codex/skills/`），通过 `$personalized-ai-teaching` 明确调用。不要只复制 `SKILL.md` 而遗漏 `references/`。

## 使用示例

- 学习引导：`使用 AI个性化教学引擎，帮孩子理解为什么14÷4有余数。`
- 开放问题：`使用 AI个性化教学引擎，和孩子一起探究未来几年AI会怎样影响写作学习。`
- 家庭方法：`分析我提供的教育资料，提炼可供试用的教学方法，让我审核后选择是否加入本次辅导。`
- 家长提示词：`生成可复制到其他通用模型的中等长度学习辅导提示词。`

**使用者提示：用户提供的资料须合法获取并合法使用。** 本工具不要求提供孩子的真实姓名、住址、学校或其他无关个人信息。

## 运行与维护

- 首次明确进入学习辅导时读取 `ai-era-teaching-methods.md`、`fundamental-education.md` 和 `interaction-router.md`。若必需文件不可读，应说明缺口。
- 后续仅在**新题/新任务、从无关话题返回、意外反馈需要重判、准备切换或组合方法**时重读 Router；同题正常往来无需每次重读。
- 如果不能把当前方法展开成本轮具体教学动作，或不确定孩子不同回应时如何继续，从 `ai-era-m1.md` 至 `ai-era-m5.md` 定向补读对应方法。
- M1–M5 的独立文件由 `tools/generate_ai_era_shards.py` 从完整版自动提取，不独立手工编辑；完整方法库是唯一编辑源。
- 使用 `python skills/personalized-ai-teaching/tests/validate_package.py .` 检查静态文件结构、版本、分章一致性及打包完整性。该校验不执行包内生成脚本，也不代替真实模型对话或儿童教学效果测试。
